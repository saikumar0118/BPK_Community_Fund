🏛️ BPK Community Fund — 10-Step Visual Flowchart

Follow these 10 steps sequentially to set up, test, and upload the project to GitHub.

1
Install Required Software Prerequisites
Install Python 3.10+, MySQL Server/Workbench, Git, and VS Code on your Windows PC.
python --version  |  git --version  |  mysql --version
▼
2
Place Project Folders Structure
Keep project at D:\BPK_Community_Fund. BackEnd folder holds Python code; FrontEnd folder holds HTML/CSS/JS.
D:\BPK_Community_Fund\BackEnd   |   D:\BPK_Community_Fund\FrontEnd
▼
3
Configure MySQL Password in Code Settings
Open BackEnd/database.py (Line 15). Replace root:root with your actual MySQL password.
DATABASE_URL = "mysql+pymysql://root:YOUR_PASSWORD@localhost:3306/pbk_db"
▼
4
Create Database & All 13 Tables Database
Run our 1-click Python initializer. It creates pbk_db, all 13 tables, and the default Super Admin.
cd D:\BPK_Community_Fund\BackEnd ; python init_db.py
▼
5
Setup Python Virtual Environment Packages
Create isolated virtual environment and install FastAPI, Uvicorn, SQLAlchemy, and PyMySQL.
python -m venv venv ; .\venv\Scripts\Activate.ps1 ; pip install -r requirements.txt
▼
6
Start FastAPI Backend Server API Live
Start the Uvicorn server at port 8000. Keep this terminal open! Visit http://127.0.0.1:8000/docs to test API.
uvicorn main:app --reload --host 127.0.0.1 --port 8000
▼
7
Open Frontend Web Portals UI
Open Windows File Explorer and double-click HomeLogRegisPass.html, admin.html, or member.html.
FrontEnd\HomeLogRegisPass\HomeLogRegisPass.html
▼
8
Test End-to-End System Testing
Register member, login as Super Admin (admin@pbkfund.org / admin), make a donation, and download a PDF receipt.
▼
9
Check GitHub File Security Security
Only push source code. Never push the 50,000 files in venv/ or private .env passwords. Protected by .gitignore.
▼
10
Push to GitHub Box-by-Box Upload
Run standard Git commands to link your local code to your online GitHub repository.
git init ; git add . ; git commit -m "feat: initial commit" ; git push -u origin main
